# Nina's Ice Cream

A modern, incremental website for Nina's Ice Cream, a small-batch neighborhood scoop shop.

## Project structure

- `index.html` - Main website markup.
- `style.css` - Site styling and responsive layout.
- `script.js` - Lightweight interactive behavior.
- `PROMPT_LOG.md` - Running record of prompts and completed work.
- `tests/` - Future automated tests.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.

For example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
